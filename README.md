CS2053 – Computer Architecture  
Department of Computer Science and Engineering, University of Moratuwa

## Overview

- Ripes visual processor interface, register view, and memory map
- RV32I basic instruction set architecture and machine instruction formats
- Register-register arithmetic, logic, and shift operations (add, sub, and, or, sll)
- Immediate arithmetic (addi) and sign-extension mechanics
- Single-cycle processor datapath tracing and register state verification
